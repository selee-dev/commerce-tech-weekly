# commerce-tech-weekly
 
홈쇼핑 주간 기술 브리프 아카이브입니다. <br>
매주 월요일(KST 09:00) 예약 작업이 최신 업계 동향을 리서치해 브리프를 갱신하고, 날짜별 파일로 이 저장소에 쌓아둡니다.<br>
 
## 구조
 
- `docs/index.html` — 브리프 목록 페이지 (GitHub Pages 루트)<br>
- `docs/briefs/YYYY-MM-DD.html` — 날짜별 브리프 본문 (라이브커머스 아키텍처: 숏폼/라이브 스트리밍 UI·UX, Flash Sale 트래픽 분산·동시성 제어, 도입 검토 기술 스택 등)<br>

  
## GitHub Pages
 
Settings → Pages → Source: `main` 브랜치 `/docs` 폴더로 설정하면<br>
`https://selee-dev.github.io/commerce-tech-weekly/`에서 목록 페이지를 바로 볼 수 있습니다.<br>
